# Storyboard v1 (superseded, see v2 below): Core intro, 27.0s, 1080×1920, 120 BPM (every cut on a 0.5s grid)

Persistent actor: **the gradient ring** (the O of the Core logo). It forms from the scattered data, becomes the logo, opens as a portal, reappears as the hub of the diagram, glows inside the deployment boundary and closes the film. A second carried object is **the pulse**, a small violet light that travels the data path.
