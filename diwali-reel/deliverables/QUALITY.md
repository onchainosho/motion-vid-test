# Diwali greeting reel: final (v10)

**Format:** 10.0 s, 1080×1920 (9:16), 60 fps, H.264 + AAC stereo. A music-only version is included.

## Measured
| Check | Result |
|---|---|
| Copy | All six lines verbatim; "Softlabs Group & Ainfinite AI" is shown as the two supplied logos joined by "&" |
| Logos | CORE, ADAM, Softlabs Group and Ainfinite AI are unaltered and in true colour (critics r5–r8 sampled them against the source PNGs) |
| Text | Contrast ≥ 5.1:1; no clipping or collisions (critics r4–r8) |
| Holds | Longest near-still stretch 0.35 s |
| Loudness | −17.0 LUFS integrated, true peak −3.2 dBFS, loudness range 2.8 LU |
| Effects vs music, measured with the critic's own script | Pops +4.2 and +4.1 dB, sparkles +3.4 and +3.3 dB, chimes +5.3 and +3.6 dB, taps about +3.6 dB, whooshes +3.8 and +5.2 dB; 2–8 kHz spikes ≤ +7.8 dB |

## Process
Eight independent critic rounds (`../review/r1…r8-critic.md`). Every round from r5 on rated the picture ship-quality; rounds r5–r8 tuned only the audio around the bursts. The last level adjustment was measured but not re-reviewed by a critic, because the user asked to finish.

- Is the original score festive enough? It was composed in code because music libraries are blocked in this sandbox, and a licensed track could replace it.
